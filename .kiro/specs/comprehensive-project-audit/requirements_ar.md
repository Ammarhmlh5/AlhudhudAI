# مستند المتطلبات: الفحص الشامل للمشروع
# Requirements Document: Comprehensive Project Audit

## المقدمة

تم إجراء فحص فعلي ومتعمق للمشروع على جميع المستويات: قواعد البيانات، الواجهات، الأكواد، الأداء، وتطبيق الهاتف. هذا المستند يوثق جميع العيوب والمشاكل المكتشفة بناءً على فحص فعلي للكود والملفات، مع أمثلة حقيقية ومواقع دقيقة.

## المصطلحات

- **النظام (System)**: منصة بوابة الرسائل النصية ALHudhudAI
- **واجهة الإدارة (Admin_Web)**: واجهة الويب الإدارية (apps/admin-web)
- **واجهة العميل (Client_Web)**: واجهة الويب للعملاء (apps/client-web)
- **بوابة الهاتف (Mobile_Gateway)**: تطبيق بوابة الهاتف المحمول (apps/mobile_gateway)
- **مشكلة أمنية (Security_Issue)**: ثغرة قد تؤدي إلى وصول غير مصرح به أو اختراق بيانات
- **مشكلة أداء (Performance_Issue)**: مشكلة تؤثر سلباً على سرعة النظام أو استخدام الموارد
- **مشكلة جودة كود (Code_Quality_Issue)**: مشكلة في بنية الكود أو قابلية الصيانة أو أفضل الممارسات
- **حرج (Critical)**: مشاكل تشكل مخاطر أمنية فورية أو فشل في النظام
- **عالي (High)**: مشاكل تؤثر بشكل كبير على الوظائف أو الأمان
- **متوسط (Medium)**: مشاكل تؤثر على تجربة المستخدم أو قابلية الصيانة
- **منخفض (Low)**: مشاكل بسيطة أو تحسينات

- تم العثور على 50+ استدعاء يدوي في:

  - `internal/payment/manager.go` (4 مواقع)

- التأثير: تجاوز كامل لعزل المستأجرين ممكن

**11.2 PreventCrossTenantAccess middleware غير مطبق (حرج)**
- الموقع: `services/backend/internal/middleware/cross_tenant_prevention.go`
- المشكلة: Middleware موجود لكن غير مسجل في `services/backend/main.go`

- الخطر: يمكن للمستأجرين الوصول لبيانات بعضهم عبر معاملة URL/query parameter
- التأثير: تجاوز كامل لعزل المستأجرين عبر API

**11.3 TenantIsolationMiddleware مطبق جزئياً (عالي)**
- الموقع: `services/backend/main.go` السطور 300-350
- مطبق على: `/devices`, `/messaging`, `/channels`

  - `/metrics` - لا يوجد عزل مستأجرين
  - `/monitoring/tenant/:tenant_id` - يقبل أي tenant_id بدون تحقق
  - `/admin/tenants` - super admin فقط لكن لا يوجد منع cross-tenant
- الخطر: يمكن للمستخدمين المصادق عليهم الوصول للمسارات غير المحمية بـ tenant IDs أخرى
- التأثير: تسريب بيانات عبر نقاط نهاية غير محمية

**11.4 WebSocket بدون عزل مستأجرين (عالي)**

- لا يوجد تحقق JWT على اتصال WebSocket
- لا يوجد تحقق من أن المستخدم المصادق عليه ينتمي للمستأجر المطلوب
- الخطر: أي شخص يمكنه الاتصال بقناة WebSocket لأي مستأجر
- التأثير: تسريب بيانات في الوقت الفعلي، اعتراض رسائل

**11.5 تعيين سياق المستأجر يدوياً (عالي)**

- النمط: `db.Exec("SET app.current_tenant = $1", tenantID)`
- الخطر: المطور ينسى تعيين السياق → تجاوز RLS
- التأثير: عزل مستأجرين غير متسق، عبء صيانة

**11.6 تغطية RLS غير كاملة (متوسط)**

- RLS مفقود على جداول حرجة:
  - `packages` - بيانات التسعير والباقات
  - `subscriptions` - معلومات اشتراك المستأجر
  - `rollover_messages` - بيانات ترحيل الرسائل
  - `billing_invoices` - سجلات مالية
  - `dedicated_gateways` - تعيينات البوابات
  - `resource_quotas` - حدود موارد المستأجر
  - `resource_usage` - تتبع الاستخدام
  - `gateway_users` - حسابات مستخدمي البوابة
  - `gateway_api_keys` - مفاتيح مصادقة API
  - `gateway_statistics` - بيانات أداء البوابة
  - `payment_transactions` - سجلات الدفع
  - `referrals` - بيانات برنامج الإحالة
  - `promo_codes` - أكواد ترويجية
- الخطر: استعلامات قاعدة بيانات مباشرة يمكنها الوصول لبيانات مستأجرين آخرين
- التأثير: عزل مستأجرين جزئي فقط

**11.7 لا توجد اختبارات عزل شاملة (متوسط)**

**12.2 race condition في خصم الرصيد (متوسط)**

- التطبيق الحالي يستخدم منطق إعادة المحاولة مع exponential backoff (جيد)

**12.3 rollback معاملة غير كامل (متوسط)**

- الخطر: مال مخصوم بدون سجل محاسبي
- التأثير: تناقض محاسبي، صعوبة التسوية

**12.4 audit trail غير متسق (متوسط)**

**12.5 عدم وجود آلية تسوية (متوسط)**

## الخلاصة النهائية الشاملة

هذا التدقيق الشامل حدد **134 مشكلة متميزة** عبر **15 فئة** من خلال فحص فعلي للكود. التدقيق غطى:

2. **عزل المستأجرين** - RLS غير مفعّل، middleware مفقود، ثغرات WebSocket
3. **المحاسبة المالية** - idempotency مفقود، سجلات تدقيق غير مكتملة، لا توجد مطابقة
4. **واجهة الإدارة** - 23 مشكلة تشمل ميزات مفقودة، تطبيقات غير مكتملة، UX سيء

6. **استيراد Excel** - 15 مشكلة تشمل مخاطر أمنية، فجوات تحقق، مشاكل أداء
7. **جودة الكود** - فجوات اختبار، معالجة أخطاء، حاجة لترحيل TypeScript
8. **الأداء** - Debouncing، pagination، caching، تحديثات فورية
9. **قاعدة البيانات** - فهارس مفقودة، استعلامات SELECT *، عمليات جماعية
10. **تطبيق الهاتف** - أخطاء تجميع، استنزاف بطارية، معالجة أخطاء
11. **البنية المعمارية** - تكرار كود، تجريدات مفقودة، فصل المسؤوليات
