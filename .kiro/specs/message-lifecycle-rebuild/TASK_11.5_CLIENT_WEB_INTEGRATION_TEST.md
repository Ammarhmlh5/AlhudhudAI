## المتطلبات الأولية

### 1. تشغيل البنية التحتية

```bash
# تشغيل Docker Compose (PostgreSQL + Redis)
docker-compose up -d

# تشغيل Migrations
cd services/backend
go run cmd/migrate/main.go up
```

### 2. تشغيل Backend

```bash
cd services/backend
go run main.go
```

**التحقق:**
- Backend يعمل على `http://localhost:8080`
- يظهر log: "Server started on :8080"

### 3. تشغيل client-web

```bash
cd apps/client-web
npm install
npm run dev
```

**التحقق:**
- client-web يعمل على `http://localhost:5174`
- لا توجد أخطاء في console

## ملاحظات للمطورين

### 1. إذا واجهت مشاكل في CORS

تأكد من أن Backend يسمح بـ origin الصحيح:

```go
// في main.go
AllowOrigins: []string{"http://localhost:5174"}
```

### 2. إذا واجهت مشاكل في WebSocket

تأكد من أن WebSocket endpoint صحيح:

```javascript
// في client-web
const ws = new WebSocket('ws://localhost:8080/ws?tenant_id=...');
```

### 3. إذا واجهت مشاكل في Authentication

تأكد من أن JWT Token أو API Key يُرسل في الـ headers:

```javascript
// في client-web
headers: {
  'Authorization': `Bearer ${token}`
  // أو
  'X-API-Key': apiKey
}
```

### 4. إذا واجهت مشاكل في Rate Limiting

تأكد من أن Rate Limiting منفصل لكل tenant:

```go
// في rate_limiter.go
key := fmt.Sprintf("rate_limit:%s", tenantID)
```
