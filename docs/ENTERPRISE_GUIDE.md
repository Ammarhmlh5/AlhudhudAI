## مقدمة عن البوابات المخصصة

### ما هي البوابة المخصصة؟

البوابة المخصصة هي بنية تحتية كاملة لإرسال الرسائل القصيرة، مخصصة لشركتك فقط. تحصل على:

- **بوابة منفصلة** بمعرفات خاصة بك
- **اتصال مباشر** بشركة الاتصالات
- **حصص موردية مخصصة** (CPU، RAM، Bandwidth)
- **إدارة كاملة** للمستخدمين ومفاتيح API
- **تقارير وإحصائيات** منفصلة ومفصلة
- **دعم فني** مخصص

### نموذج العمل المالي

#### ما تدفعه شركتك:

1. **لشركة الاتصالات مباشرة**:
   - تكلفة الرسائل المرسلة
   - حسب اتفاقيتك الخاصة مع شركة الاتصالات

2. **للمنصة**:
   - رسوم الاشتراك (شهري أو سنوي)
   - رسوم إيجار السيرفر

#### ما لا تدفعه:

- ❌ عمولة على الرسائل للمنصة
- ❌ رسوم إضافية على الاستخدام

#### دور المنصة:

- ✅ توفير البنية التحتية
- ✅ إدارة السيرفرات
- ✅ مراقبة رصيدك لدى شركة الاتصالات
- ✅ إرسال تنبيهات عند انخفاض الرصيد
- ✅ الدعم الفني


### المزايا الرئيسية

#### 1. العزل التام

- بياناتك منفصلة تماماً عن الشركات الأخرى
- لا يمكن لأي شركة أخرى الوصول لبياناتك
- موارد مخصصة لك فقط

#### 2. التحكم الكامل

- إدارة المستخدمين والصلاحيات
- إنشاء وإدارة API Keys
- تخصيص الإعدادات حسب احتياجاتك

#### 3. الأداء العالي

- حصص موردية مضمونة
- لا تأثير من استخدام الشركات الأخرى
- إنتاجية عالية (رسائل/ثانية)

#### 4. الشفافية

- تقارير مفصلة عن كل شيء
- مراقبة مباشرة للأداء
- تنبيهات فورية عند أي مشكلة

## الوصول إلى لوحة التحكم

### تسجيل الدخول

1. **افتح المتصفح** وانتقل إلى:
   ```
   https://admin.your-platform.com
   ```

2. **أدخل بيانات الدخول**:
   - البريد الإلكتروني
   - كلمة المرور

3. **انقر على "تسجيل الدخول"**

### الواجهة الرئيسية

بعد تسجيل الدخول، ستجد:

#### القائمة الجانبية:

- **لوحة التحكم**: نظرة عامة على بوابتك
- **إرسال الرسائل**: إرسال رسائل مباشرة
- **سجل الرسائل**: عرض جميع الرسائل المرسلة
- **المستخدمون**: إدارة مستخدمي البوابة
- **API Keys**: إدارة مفاتيح API
- **التقارير**: تقارير مفصلة
- **الإعدادات**: إعدادات البوابة
- **الدعم**: التواصل مع الدعم الفني

#### الشريط العلوي:

- **اسم البوابة**: اسم بوابتك المخصصة
- **الإشعارات**: التنبيهات والإشعارات
- **الملف الشخصي**: إعداداتك الشخصية
- **تسجيل الخروج**: الخروج من النظام

## إدارة البوابة المخصصة

### لوحة التحكم الرئيسية

عند فتح لوحة التحكم، ستجد:

#### 1. حالة البوابة

```
┌─────────────────────────────────────┐
│ حالة البوابة: ● نشطة              │
│ وقت التشغيل: 99.95%                │
│ آخر فحص: منذ دقيقة واحدة           │
└─────────────────────────────────────┘
```

- **نشطة**: البوابة تعمل بشكل طبيعي
- **صيانة**: صيانة مجدولة
- **غير متاحة**: مشكلة تقنية (اتصل بالدعم)

#### 2. إحصائيات اليوم

```
┌──────────────────┬──────────────────┬──────────────────┐
│ رسائل مرسلة      │ معدل النجاح      │ وقت الاستجابة    │
│ 45,230          │ 98.5%           │ 245ms           │
└──────────────────┴──────────────────┴──────────────────┘
```

#### 3. رصيد شركة الاتصالات

```
┌─────────────────────────────────────┐
│ الرصيد الحالي: 125,000 ريال        │
│ عتبة التنبيه: 50,000 ريال          │
│ الحالة: ● طبيعي                    │
│ آخر فحص: منذ 15 دقيقة              │
└─────────────────────────────────────┘
```

⚠️ **مهم**: هذا هو رصيدك لدى شركة الاتصالات. المنصة تراقبه فقط وترسل تنبيهات. أنت مسؤول عن شحن الرصيد مباشرة مع شركة الاتصالات.

#### 4. استخدام الموارد

```
┌─────────────────────────────────────┐
│ CPU:       ████████░░ 80% / 4 cores│
│ RAM:       ██████░░░░ 60% / 8 GB   │
│ Bandwidth: ███░░░░░░░ 30% / 100 GB │
└─────────────────────────────────────┘
```

#### 5. التنبيهات النشطة

```
┌─────────────────────────────────────┐
│ ⚠️ استخدام CPU مرتفع (85%)         │
│ ℹ️ صيانة مجدولة غداً الساعة 2 صباحاً│
└─────────────────────────────────────┘
```

### عرض تفاصيل البوابة

#### الوصول:

1. **انقر على "الإعدادات"** في القائمة الجانبية
2. **انتقل إلى تبويب "معلومات البوابة"**

#### ما ستجده:

**المعلومات الأساسية:**
- اسم البوابة
- رمز البوابة (Gateway Code)
- تاريخ الإنشاء
- نوع الاشتراك (شهري/سنوي)

**معلومات الاتصال:**
- نوع الاتصال (HTTP، SMPP)
- عنوان API
- اسم المستخدم (معروض جزئياً للأمان)

**الحدود والحصص:**
- الإنتاجية: رسائل/ثانية
- الحد اليومي: رسائل/يوم
- الحد الشهري: رسائل/شهر

**الموارد المخصصة:**
- CPU: عدد الأنوية
- RAM: حجم الذاكرة
- Storage: مساحة التخزين
- Bandwidth: النطاق الترددي الشهري


### تعديل إعدادات البوابة

#### ما يمكنك تعديله:

✅ **يمكن تعديله بنفسك:**
- اسم البوابة (للعرض فقط)
- عتبة تنبيه الرصيد
- تفضيلات الإشعارات

⚠️ **يحتاج طلب من الدعم:**
- زيادة الحصص الموردية
- تغيير نوع الاشتراك
- تعديل معلومات الاتصال

#### تعديل عتبة تنبيه الرصيد:

1. **انتقل إلى "الإعدادات" > "مراقبة الرصيد"**
2. **أدخل المبلغ الجديد** (بالريال اليمني)
3. **انقر على "حفظ"**

مثال:
```
عتبة التنبيه الحالية: 50,000 ريال
عتبة التنبيه الجديدة: 100,000 ريال
```

عند انخفاض رصيدك لدى شركة الاتصالات عن هذا المبلغ، ستتلقى تنبيه فوري.

### مراقبة الأداء

#### عرض الأداء الحالي:

1. **انتقل إلى "لوحة التحكم"**
2. **انظر إلى قسم "الأداء"**

#### المقاييس المعروضة:

**وقت الاستجابة:**
- متوسط: الوقت المتوسط للرد على الطلبات
- أدنى: أسرع وقت استجابة
- أقصى: أبطأ وقت استجابة
- الهدف: أقل من 500ms

**معدل النجاح:**
- نسبة الرسائل المسلّمة بنجاح
- الهدف: 95% أو أعلى

**الإنتاجية:**
- رسائل/ثانية الحالية
- رسائل/ساعة
- رسائل/يوم

**وقت التشغيل (Uptime):**
- نسبة الوقت الذي كانت فيه البوابة متاحة
- الهدف: 99.9% أو أعلى

### طلب زيادة الموارد

إذا احتجت لزيادة الحصص الموردية:

#### الخطوات:

1. **انتقل إلى "الإعدادات" > "الموارد"**
2. **انقر على "طلب زيادة"**
3. **املأ النموذج:**
   - نوع المورد (CPU، RAM، Bandwidth)
   - القيمة الحالية
   - القيمة المطلوبة
   - السبب
4. **أرسل الطلب**

سيتم مراجعة طلبك والرد عليك خلال 24 ساعة.

#### مثال:

```
نوع المورد: CPU
القيمة الحالية: 4 cores
القيمة المطلوبة: 8 cores
السبب: زيادة متوقعة في حجم الإرسال خلال الحملة التسويقية القادمة
```

## إدارة المستخدمين

### نظرة عامة

يمكنك إضافة مستخدمين متعددين لبوابتك المخصصة، كل مستخدم بصلاحيات محددة.

### الأدوار المتاحة

#### 1. مدير (Admin)

**الصلاحيات:**
- ✅ إدارة البوابة والإعدادات
- ✅ إدارة المستخدمين
- ✅ إدارة API Keys
- ✅ إرسال الرسائل
- ✅ عرض جميع التقارير
- ✅ تعديل الإعدادات

**متى تستخدمه:**
- المدير العام للبوابة
- مدير تقنية المعلومات
- الأشخاص الذين يحتاجون صلاحيات كاملة

#### 2. مشغّل (Operator)

**الصلاحيات:**
- ✅ إرسال الرسائل
- ✅ عرض سجل الرسائل
- ✅ عرض التقارير
- ✅ عرض الإحصائيات
- ❌ تعديل الإعدادات
- ❌ إدارة المستخدمين
- ❌ إدارة API Keys

**متى تستخدمه:**
- موظفي التسويق
- موظفي خدمة العملاء
- الأشخاص الذين يرسلون الرسائل فقط

#### 3. مشاهد (Viewer)

**الصلاحيات:**
- ✅ عرض التقارير فقط
- ✅ عرض الإحصائيات
- ❌ إرسال الرسائل
- ❌ تعديل أي شيء

**متى تستخدمه:**
- المديرين التنفيذيين
- المحللين
- الأشخاص الذين يحتاجون رؤية فقط

### عرض المستخدمين الحاليين

#### الوصول:

1. **انقر على "المستخدمون"** في القائمة الجانبية
2. **ستظهر قائمة بجميع المستخدمين**

#### ما ستجده:

```
┌────────────────────────────────────────────────────────────┐
│ الاسم          │ البريد الإلكتروني    │ الدور    │ الحالة │
├────────────────────────────────────────────────────────────┤
│ أحمد محمد      │ ahmed@company.com    │ مدير     │ نشط   │
│ فاطمة علي      │ fatima@company.com   │ مشغّل    │ نشط   │
│ خالد حسن       │ khaled@company.com   │ مشاهد    │ معطّل │
└────────────────────────────────────────────────────────────┘
```

### إضافة مستخدم جديد

#### الخطوات:

1. **انقر على زر "إضافة مستخدم"**

2. **املأ النموذج:**
   - **البريد الإلكتروني**: البريد الإلكتروني للمستخدم
   - **الاسم الكامل**: الاسم الكامل
   - **الدور**: اختر من القائمة (مدير، مشغّل، مشاهد)
   - **رقم الهاتف**: اختياري

3. **صلاحيات مخصصة** (اختياري):
   - يمكنك تخصيص صلاحيات دقيقة لكل مستخدم
   - مثال: السماح بإرسال الرسائل فقط لقائمة معينة

4. **انقر على "إضافة"**

#### ما يحدث بعد الإضافة:

- ✉️ يتم إرسال دعوة للمستخدم عبر البريد الإلكتروني
- 🔑 يحصل المستخدم على رابط لإنشاء كلمة مرور
- ⏰ الدعوة صالحة لمدة 7 أيام
- 🔄 يمكنك إعادة إرسال الدعوة إذا انتهت

#### مثال:

```
البريد الإلكتروني: sara@company.com
الاسم الكامل: سارة أحمد
الدور: مشغّل
رقم الهاتف: +967 777 123 456

صلاحيات مخصصة:
☑ إرسال رسائل تسويقية
☑ عرض تقارير الحملات
☐ إرسال رسائل إدارية
```


### تعديل صلاحيات مستخدم

#### الخطوات:

1. **ابحث عن المستخدم** في القائمة
2. **انقر على أيقونة التعديل** (قلم)
3. **عدّل البيانات:**
   - الدور
   - الصلاحيات المخصصة
   - الحالة (نشط/معطّل)
4. **احفظ التغييرات**

⚠️ **ملاحظة**: التغييرات تطبق فوراً. المستخدم سيحتاج لتسجيل الدخول مرة أخرى.

### تعطيل أو حذف مستخدم

#### تعطيل مؤقت:

استخدم هذا عندما:
- المستخدم في إجازة
- تريد إيقاف الوصول مؤقتاً
- تحقيق أمني

**الخطوات:**
1. **ابحث عن المستخدم**
2. **انقر على "تعطيل"**
3. **أكد العملية**

النتيجة:
- ❌ لا يمكن للمستخدم تسجيل الدخول
- ✅ البيانات محفوظة
- ✅ يمكن إعادة التفعيل في أي وقت

#### حذف نهائي:

استخدم هذا عندما:
- المستخدم ترك الشركة
- لن يحتاج الوصول مرة أخرى

**الخطوات:**
1. **ابحث عن المستخدم**
2. **انقر على "حذف"**
3. **أكد العملية**

⚠️ **تحذير**: الحذف نهائي ولا يمكن التراجع عنه.

### الصلاحيات المخصصة

يمكنك تخصيص صلاحيات دقيقة لكل مستخدم:

#### أمثلة:

**مشغّل محدود:**
```
☑ إرسال رسائل (حد أقصى 1000/يوم)
☑ عرض سجل رسائله فقط
☐ عرض رسائل المستخدمين الآخرين
☐ تصدير التقارير
```

**مشاهد متقدم:**
```

☑ تصدير التقارير
☑ عرض الإحصائيات المالية
☐ إرسال الرسائل
```

**مدير محدود:**
```
☑ إدارة المستخدمين
☑ إدارة API Keys
☐ تعديل إعدادات البوابة
☐ عرض التقارير المالية
```

### سجل نشاط المستخدمين

لعرض نشاط مستخدم معين:

1. **انقر على اسم المستخدم**
2. **انتقل إلى تبويب "سجل النشاط"**
3. **شاهد:**
   - تسجيل الدخول/الخروج
   - الرسائل المرسلة
   - التقارير المعروضة
   - التغييرات المطبقة

## إدارة API Keys

### نظرة عامة

API Keys تسمح لأنظمتك الداخلية بالتكامل مع البوابة برمجياً. كل مفتاح له صلاحيات محددة وحدود استخدام.

### عرض API Keys الحالية

#### الوصول:

1. **انقر على "API Keys"** في القائمة الجانبية
2. **ستظهر قائمة بجميع المفاتيح**

#### ما ستجده:

```
┌──────────────────────────────────────────────────────────────────┐
│ الاسم              │ الحالة │ آخر استخدام    │ الاستخدام/الحد    │
├──────────────────────────────────────────────────────────────────┤
│ Production API     │ نشط   │ منذ 5 دقائق    │ 1,234 / 10,000   │
│ Development API    │ نشط   │ منذ ساعة       │ 45 / 1,000       │
│ Legacy API         │ معطّل │ منذ 30 يوم     │ 0 / 5,000        │
└──────────────────────────────────────────────────────────────────┘
```


### إنشاء API Key جديد

#### الخطوات:

1. **انقر على زر "إنشاء مفتاح جديد"**

2. **املأ النموذج:**

   **المعلومات الأساسية:**
   - **اسم المفتاح**: اسم واضح (مثال: Production API Key)
   - **الوصف**: وصف مختصر للاستخدام

   **الصلاحيات:**
   - ☑ إرسال الرسائل
   - ☑ الاستعلام عن حالة الرسائل
   - ☑ عرض الإحصائيات
   - ☐ إدارة المستخدمين (غير مسموح عادة)

   **حدود الاستخدام:**
   - **Rate Limit**: عدد الطلبات/دقيقة (مثال: 100)
   - **Daily Limit**: عدد الطلبات/يوم (مثال: 10,000)

   **الأمان:**
   - **IP Whitelisting**: قائمة عناوين IP المسموحة (اختياري)
   - **تاريخ الانتهاء**: متى ينتهي المفتاح (اختياري)

3. **انقر على "إنشاء"**

#### ⚠️ مهم جداً:

```
┌─────────────────────────────────────────────────────────┐
│ ⚠️ احفظ هذا المفتاح في مكان آمن!                      │
│                                                         │
│ API Key: sk_live_REPLACED_FOR_PUBLIC_REPO_example │
│                                                         │
│ هذا المفتاح يظهر مرة واحدة فقط.                       │
│ لن تتمكن من رؤيته مرة أخرى.                          │
└─────────────────────────────────────────────────────────┘
```

احفظ المفتاح في:
- ✅ مدير كلمات المرور (1Password، LastPass)
- ✅ متغيرات البيئة في السيرفر
- ✅ خزنة أسرار (AWS Secrets Manager، HashiCorp Vault)
- ❌ لا تحفظه في الكود المصدري
- ❌ لا تشاركه عبر البريد الإلكتروني

#### مثال:

```
اسم المفتاح: Production API - Marketing System
الوصف: مفتاح API لنظام التسويق الآلي

الصلاحيات:
☑ إرسال الرسائل
☑ الاستعلام عن حالة الرسائل
☑ عرض الإحصائيات

حدود الاستخدام:
Rate Limit: 100 طلب/دقيقة
Daily Limit: 50,000 طلب/يوم

الأمان:
IP Whitelisting: 
  - 192.168.1.100
  - 192.168.1.101
تاريخ الانتهاء: 31 ديسمبر 2024
```

### استخدام API Key

#### في الكود:

**cURL:**
```bash
curl -X POST https://api.your-platform.com/v1/messages \
  -H "Authorization: Bearer sk_live_abc123..." \
  -H "Content-Type: application/json" \
```

#### عرض الإحصائيات:

2. **شاهد:**
   - عدد الطلبات اليوم
   - عدد الطلبات هذا الشهر

### تعطيل أو حذف API Key

#### تعطيل مؤقت:

استخدم هذا عندما:
- تشك في اختراق المفتاح
- تريد إيقاف نظام مؤقتاً
- اختبار أو صيانة

**الخطوات:**
1. **ابحث عن المفتاح**
2. **انقر على "تعطيل"**
3. **أكد العملية**

النتيجة:
- ❌ جميع الطلبات باستخدام هذا المفتاح سترفض
- ✅ يمكن إعادة التفعيل في أي وقت

#### حذف نهائي:

استخدم هذا عندما:
- لن تحتاج المفتاح مرة أخرى
- تريد إنشاء مفتاح جديد بدلاً منه

**الخطوات:**
1. **ابحث عن المفتاح**
2. **انقر على "حذف"**
3. **أكد العملية**

⚠️ **تحذير**: الحذف نهائي. تأكد من تحديث أنظمتك قبل الحذف.

### IP Whitelisting

لزيادة الأمان، يمكنك تحديد عناوين IP المسموح لها باستخدام المفتاح.

#### إضافة IP:

1. **افتح تفاصيل المفتاح**
2. **انتقل إلى "IP Whitelisting"**
3. **انقر على "إضافة IP"**
4. **أدخل عنوان IP** (مثال: 192.168.1.100)
5. **أضف وصف** (مثال: Production Server 1)
6. **احفظ**

#### مثال:

```
عناوين IP المسموحة:
┌────────────────────────────────────────┐
│ 192.168.1.100  │ Production Server 1  │
│ 192.168.1.101  │ Production Server 2  │
│ 10.0.0.50      │ Backup Server        │
└────────────────────────────────────────┘
```

إذا حاول أي IP آخر استخدام المفتاح، سيتم رفض الطلب.

### تجديد API Key

إذا انتهت صلاحية المفتاح أو تريد تجديده:

1. **افتح تفاصيل المفتاح**
2. **انقر على "تجديد"**
3. **اختر:**
   - تجديد بنفس الإعدادات
   - تجديد مع تعديل الإعدادات
4. **سيتم إنشاء مفتاح جديد**

⚠️ **ملاحظة**: المفتاح القديم سيتوقف عن العمل فوراً. حدّث أنظمتك بالمفتاح الجديد.

## أفضل الممارسات

### الأمان

#### 1. إدارة المستخدمين

✅ **افعل:**
- امنح كل مستخدم الصلاحيات التي يحتاجها فقط
- راجع قائمة المستخدمين شهرياً
- عطّل حسابات الموظفين الذين تركوا الشركة فوراً
- استخدم كلمات مرور قوية
- فعّل المصادقة الثنائية (2FA)

❌ **لا تفعل:**
- لا تشارك حسابات المستخدمين
- لا تمنح صلاحيات مدير للجميع
- لا تترك حسابات معطلة دون حذف

#### 2. إدارة API Keys

✅ **افعل:**
- استخدم مفاتيح مختلفة للإنتاج والتطوير
- فعّل IP Whitelisting
- حدد تاريخ انتهاء للمفاتيح
- راقب استخدام المفاتيح
- جدد المفاتيح دورياً (كل 6 أشهر)

❌ **لا تفعل:**
- لا تحفظ المفاتيح في الكود المصدري
- لا تشارك المفاتيح عبر البريد الإلكتروني
- لا تستخدم نفس المفتاح في أنظمة متعددة

#### 3. حماية البيانات

✅ **افعل:**
- احتفظ بنسخ احتياطية من البيانات المهمة
- راجع سجل النشاط دورياً
- أبلغ عن أي نشاط مشبوه فوراً

❌ **لا تفعل:**
- لا تحفظ بيانات حساسة في أماكن غير آمنة
- لا تتجاهل التنبيهات الأمنية


### الأداء

#### 1. مراقبة الموارد

✅ **افعل:**
- راقب استخدام الموارد يومياً
- اطلب زيادة الموارد قبل الوصول للحد (عند 80%)
- راجع أوقات الذروة وخطط لها
- حسّن أنظمتك لتقليل الاستهلاك

❌ **لا تفعل:**
- لا تنتظر حتى نفاد الموارد
- لا تتجاهل تنبيهات الموارد

#### 2. تحسين الإرسال

✅ **افعل:**
- استخدم Batch API لإرسال رسائل متعددة
- وزع الإرسال على مدار اليوم
- تجنب الإرسال الكثيف في وقت واحد
- استخدم Rate Limiting بحكمة

❌ **لا تفعل:**
- لا ترسل آلاف الرسائل دفعة واحدة
- لا تتجاوز حدود Rate Limit

#### 3. معالجة الأخطاء

✅ **افعل:**
- راجع تقرير الأخطاء أسبوعياً
- حدد الأنماط المتكررة
- اتخذ إجراءات تصحيحية
- تواصل مع الدعم عند الحاجة

❌ **لا تفعل:**
- لا تتجاهل الأخطاء المتكررة
- لا تفترض أن المشكلة ستحل نفسها

### التكاليف

#### 1. إدارة الرصيد

✅ **افعل:**
- راقب رصيدك لدى شركة الاتصالات يومياً
- اشحن الرصيد قبل نفاده

## الأسئلة الشائعة

### عن البوابة المخصصة

**س: ما الفرق بين البوابة المخصصة والباقات العادية؟**

ج: البوابة المخصصة توفر:
- بنية تحتية منفصلة تماماً
- موارد مخصصة لك فقط
- تحكم كامل في الإعدادات
- دعم فني مخصص
- مناسبة للشركات الكبيرة بحجم إرسال عالي

**س: كيف أدفع تكلفة الرسائل؟**

ج: تدفع مباشرة لشركة الاتصالات حسب اتفاقيتك معهم. المنصة تتقاضى فقط رسوم الاشتراك والإيجار.

**س: ماذا يحدث إذا نفد رصيدي لدى شركة الاتصالات؟**

ج: لن تتمكن من إرسال رسائل جديدة حتى تشحن رصيدك. المنصة ترسل تنبيهات مسبقة لتجنب هذا.


### عن المستخدمين

**س: كم عدد المستخدمين الذي يمكنني إضافتهم؟**

ج: لا يوجد حد أقصى. يمكنك إضافة عدد غير محدود من المستخدمين.

**س: هل يمكنني تخصيص صلاحيات دقيقة لكل مستخدم؟**

ج: نعم، بالإضافة للأدوار الأساسية (مدير، مشغّل، مشاهد)، يمكنك تخصيص صلاحيات دقيقة.

**س: ماذا يحدث إذا نسي مستخدم كلمة المرور؟**

ج: يمكنه استخدام "نسيت كلمة المرور" في صفحة تسجيل الدخول. أو يمكنك كمدير إعادة تعيين كلمة المرور.

### عن API Keys

**س: كم عدد API Keys الذي يمكنني إنشاؤه؟**

ج: لا يوجد حد أقصى. يمكنك إنشاء عدد غير محدود من المفاتيح.

**س: هل يمكنني استخدام نفس المفتاح في أنظمة متعددة؟**

ج: تقنياً نعم، لكن لا ننصح بذلك. من الأفضل إنشاء مفتاح منفصل لكل نظام للأمان والمراقبة.

**س: ماذا أفعل إذا فقدت API Key؟**

ج: لا يمكن استرجاع المفتاح. يجب عليك:
1. تعطيل المفتاح القديم فوراً
2. إنشاء مفتاح جديد
3. تحديث أنظمتك بالمفتاح الجديد

**س: هل API Keys لها تاريخ انتهاء؟**

ج: يمكنك تحديد تاريخ انتهاء اختياري عند الإنشاء. إذا لم تحدد، المفتاح يبقى نشطاً إلى الأبد.

### عن التقارير

**س: كم مدة الاحتفاظ بالتقارير؟**

ج: نحتفظ بالبيانات لمدة 90 يوم. يمكنك تصدير التقارير للأرشفة طويلة الأمد.

**س: هل يمكنني جدولة إرسال التقارير تلقائياً؟**

ج: نعم، يمكنك جدولة أي تقرير ليتم إرساله تلقائياً (يومي، أسبوعي، شهري).

**س: ما الفرق بين تقرير الأداء وتقرير الاستخدام؟**

ج: 
- تقرير الأداء: يركز على جودة الخدمة (وقت التشغيل، وقت الاستجابة، معدل النجاح)
- تقرير الاستخدام: يركز على الكمية (عدد الرسائل، استخدام الموارد، أوقات الذروة)

### عن المراقبة

**س: كم مرة يتم فحص رصيدي لدى شركة الاتصالات؟**

ج: كل ساعة افتراضياً. يمكنك تغيير التكرار من الإعدادات.

**س: ماذا يحدث عند تلقي تنبيه حرج؟**

ج: يتم إرسال التنبيه فوراً عبر جميع القنوات المفعّلة (بريد، SMS، Slack). يجب عليك التحقق والاستجابة بأسرع وقت.

**س: هل يمكنني تخصيص عتبات التنبيهات؟**

ج: نعم، يمكنك تخصيص عتبة تنبيه الرصيد. العتبات الأخرى (CPU، RAM، إلخ) يتم تحديدها من قبل المنصة لضمان الأداء الأمثل.

### عن الدعم

**س: كيف أتواصل مع الدعم الفني؟**

ج: يمكنك:
- فتح تذكرة من لوحة التحكم (الإعدادات > الدعم)
- إرسال بريد إلكتروني: support@your-platform.com
- الاتصال: +967 1 234 567 (أوقات العمل)

ج: 
- الدعم العادي: الأحد - الخميس، 9 صباحاً - 5 مساءً
- الدعم الطارئ: 24/7 للمشاكل الحرجة

**س: ما هو وقت الاستجابة المتوقع؟**

ج:
- مشاكل حرجة: خلال ساعة
- مشاكل عادية: خلال 4 ساعات
- استفسارات عامة: خلال 24 ساعة
