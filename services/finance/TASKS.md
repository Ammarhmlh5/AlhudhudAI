# مهام تنفيذ النظام المالي المعزول (القيد المزدوج)

## ✅ المهام المكتملة

| الحالة | المهمة | الوصف |
|:------:|--------|-------|
| ✅ | تهيئة المشروع والهيكلة | إنشاء مجلد `finance`، النماذج `models.go`، وإعداد `gorm`. |
| ✅ | **المهمة 1: خدمة القيود المحاسبية (Journal Entry Service)** | برمجة دالة `CreateJournalEntry` مع ضمان: <br>1. استخدام `Transaction` ACID.<br>2. التأكد أن مجموع الدائن = مجموع المدين.<br>3. التسجيل الدقيق في جدولي الرأس والسطور. |
| ✅ | **المهمة 2: خدمة دفتر الأستاذ والرصيد (Ledger & Balance Service)** | برمجة دالة `GetAccountBalance` لاستخراج الرصيد الفعلي للحساب بناءً على طبيعته (مدين/دائن) من سطور القيود دون الاعتماد على رقم ثابت. |
| ✅ | **المهمة 3: إنشاء الحسابات الافتراضية (Seeder)** | برمجة سكربت أولي يُنشئ الدليل المحاسبي الأساسي (الأصول النقدية، حسابات الإيرادات، ضريبة القيمة المضافة). |
| ✅ | **المهمة 4: إنشاء حسابات العملاء الآلية (Dynamic Accounts)** | برمجة دالة لإنشاء حساب فرعي (Sub-Account) للعميل أو الوكيل تحت بند الخصوم (أرصدة المحافظ) عند تسجيله. |
| ✅ | **المهمة 5: واجهات الربط الداخلية (Internal APIs)** | بناء `HTTP/REST Handlers` ليقوم النظام الأساسي (بوابة الرسائل) باستدعائها لشحن الرصيد المالي أو استقطاع قيمة اشتراك/باقة. |
| ✅ | **المهمة 6: الفواتير (Invoicing)** | إنشاء نظام مبسط لتوليد بيانات الفاتورة الضريبية وتصديرها كـ PDF وربطها بالقيود. |
| ✅ | **المهمة 7: نقطة بدء الخدمة (main.go)** | إنشاء `cmd/main.go` لتشغيل الخدمة مع تسجيل الـ routes وتهيئة قاعدة البيانات. |
| ✅ | **المهمة 8: قائمة المعاملات (Transactions)** | إضافة `ListTransactionsHandler` لعرض جميع المعاملات من Journal Entries. |
| ✅ | **المهمة 9: قائمة الصناديق (Cashboxes)** | إضافة `ListCashboxesHandler` لعرض قائمة الصناديق من الحسابات. |
| ✅ | **المهمة 10: ربط Frontend بالـ API** | إنشاء `admin-web/src/api/finance.js` وتحديث `FinanceManager.jsx`. |
